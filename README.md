# Copilot Ops • Portal de Postulaciones (Karla)

Portal web privado y ligero para coordinación operativa entre Jesús y Karla.

## Stack
- **Framework:** Astro 6 (Static Mode)
- **CSS:** Tailwind CSS v4 con PostCSS
- **Componentes Interactivos:** React 19 (`@astrojs/react`)
- **Diseño:** Sobrio, estilo ingeniería, optimizado para tablet y móvil.

## Comandos
- `npm run dev` - Servidor de desarrollo
- `npm run build` - Compilación de producción
- `npm run preview` - Vista previa local del build
